# Student Productivity Tracker

A productivity app built for students to manage tasks, schedules, habits, and focus sessions.

## Features
- 📅 Schedule & Calendar management
- ✅ Task tracking
- ⏱️ Focus mode (Pomodoro)
- 💧 Water & Habit reminders
- 📊 Analytics & Stats
- 🌙 Dark mode support
- 📱 Android app (Capacitor)

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Capacitor (Android)
- Vite
